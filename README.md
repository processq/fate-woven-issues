# Fate Woven

Fate Woven adds spellcasting to Valheim. Level up, pick from three cards each time, and weave abilities, runes and blessings into a build of your own. This is a private beta for invited testers.

## Features

- Earn XP from fights. Every level offers three cards: pick one.
- Abilities go on your bar. Runes change how they work, and each ability gets stronger as you use it.
- Utility abilities, summons and pets, with eight elements and many statuses.
- Gods and blessings: please a god with deeds and offerings, and carry its blessing.
- Quest boards with notices that send you out to hunt, gather and clear nests. Rewards come in tiers.
- Rune Charms you craft from boss drops, and an Altar of the Gods for offerings.
- Works in multiplayer. Everyone installs the same version.

Keys: K opens the Runes panel, Z casts the readied ability, B (hold) opens the ability wheel, [ and ] step through the bar, H and J control your pets.

## Installing

Use your mod manager, which installs BepInEx and Jotunn for you. To install by hand, put BepInExPack_Valheim and Jotunn in place first, then copy the plugins/FateWoven folder from this download into BepInEx/plugins.

## Configuration

The config file is BepInEx/config/FateWoven.cfg, created the first time you run the game. Most settings are server settings, so on a server only the host's file matters. They let a host switch parts of the mod on or off, such as blessings, advanced runes and utility abilities, or list specific cards to turn off.
