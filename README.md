# Fate Woven

A full ability and build system for Valheim: draft powers, reshape them with runes, and earn the favour of the gods.

- **Guide:** https://processq.github.io/fate-woven-issues/
- **Report a bug or share an idea:** [open an issue](../../issues/new/choose). You need a free GitHub account. Tell us the version (shown in the main menu corner), what happened and any other mods you use.
- Please do not post passwords, personal details or save files here: this page is public.
